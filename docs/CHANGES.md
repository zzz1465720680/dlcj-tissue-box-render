## 一起修正的行为

### 草稿和方案完整性

读取草稿后才开放编辑，避免慢读取覆盖已做的修改。自动保存做 350ms 合并，返回、语言切换、页面隐藏时尝试刷新保存。未保存时增加离开提醒。

预设深链接被使用后清除 `preset` 参数，避免刷新时重新应用预设覆盖已调整的颜色。已有配置被替换时确认，且可以撤销。存储异常仍保留导出或离开的选择。

保存弹窗使用独立名称草稿：空名不能保存；取消不改变当前方案名；保存成功后继续修改名称可以再次保存。只翻译三个内置预设的显示名，不改内部名称，不翻译用户自己的文字和自定义名称。

### 询价、导入导出和图案

数量验证、摘要、复制失败时的手动复制入口、商家联系按钮和错误提示使用同一语言。表单内明确这不是付款或已发送订单。

JSON Schema 与三个原始预设定义不变；旧格式导入仍走原验证器。图案保留原 PNG/JPEG/WebP 校验与大小处理；补充与原 Schema 一致的 200 图层 / 6000 笔迹点上限。达到图层上限时不会再显示虚假的上传成功提示，也不会清空未添加的文字。

### 预览与异常恢复

模型不可用时不提供看似可用的相机、PNG、旋转等操作；JSON、配置编辑与咨询仍可使用。轻量预览明确标为静态预设参考，不冒充实时模型或更新后的设计截图。Studio 模块加载失败有重试与返回，不留白屏。

### 可读性与移动布局

增加导航区块定位、键盘焦点、减少动画偏好支持；调整窄屏按钮、颜色与部位选择、弹窗滚动和内容高度。手机取消挡住主要操作的大面积粘滞预览区。以 320、360、390、430、768、1024、1440px 检查没有横向溢出。

首页不加载定制用 3D 运行时与模型；保留原照片的响应式尺寸与非首屏延后加载。没有以降采样或删功能的方式压缩原 3D 模型。

## 保留的边界

原商家电话、微信与产品事实不改。价格、材料能否生产、交期仍由商家确认。访客设计仍是各自浏览器中的本地数据，不新增后台收件、登录、远程存储、在线付款或跨设备自动同步。

模型文件及材质资源保留，并不等同于已完成 GPU 验收。请结合 `TEST-REPORT.md` 和 `ACCEPTANCE.md` 使用本交付。
