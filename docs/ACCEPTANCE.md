# 发布前验收清单

先保留原站和原仓库备份；先用本地或独立预览域名检查，不直接替换正式站。

## 标准构建

- [ ] 使用项目声明的 Node 环境，`npm ci` 成功。
- [ ] `npm test` 成功；`npm run build` 的 TypeScript 检查与 Vite 构建均成功。
- [ ] 用该标准产物重复下面的检查，而不仅检查随附离线预览产物。

## 四个主要问题

- [ ] 新浏览器打开首页 → 选择 EN → 开始定制：界面、材质、部位、保存、导出、咨询、错误提示均为英文。
- [ ] EN 打开三款配色任意一款，方案正确；返回仍为 EN；刷新和再次打开仍符合所选语言。
- [ ] 桌面首页一眼能看清主产品与主按钮；区块有主次；折叠说明、FAQ 和区块导航正常。
- [ ] 320–430px 手机上三个真实预设全部可见；每一款能选中；返回按钮不隐藏。

## 草稿、方案和回退

- [ ] 修改颜色，返回首页再进入；刷新、关闭浏览器再打开；草稿均为最新。
- [ ] 从预设深链接修改后刷新，不被初始预设覆盖。
- [ ] 空方案名不能保存；取消改名不改原名；保存方案后在方案库中能打开。
- [ ] 拒绝/用尽浏览器存储时有明确提示，能下载 JSON 或确认离开，不被困在页面。
- [ ] 导出 JSON 在另一设备导入，六部位、图案、标签和独立包角均保留。

## 实际 3D 与文件

- [ ] revision7 GLB 真正加载，没有 WebGL/纹理异常；白瓷、曜石、森林三款实际效果正确。
- [ ] 材质、颜色、封边、缝线、打孔、四个包角、侧标、文字/图片/手绘全部能反映到模型。
- [ ] 缩放、旋转、视角切换、抽纸和对比正常；相机控件在加载前不可误操作。
- [ ] 多角度 PNG 成功下载，图案方向/位置正确，画面没有丢材质或空白。
- [ ] 不支持 WebGL 或启用轻量模式时提示准确；静态参考不冒充最新修改；JSON 可用。

## 手机和正式上线前

- [ ] iPhone Safari 与 Android Chrome 各检查一次，虚拟键盘不遮住关键按钮，弹窗可滚动和关闭。
- [ ] 询价数量验证、复制失败的手动复制、备注保留、电话及微信信息正确。
- [ ] HTTPS 预览站中直接打开/刷新 `/customize?lang=en` 不 404；模型、照片无 404。
- [ ] 首次进入和缓存后更新均显示同一新版本；慢手机网络可进入轻量模式。
- [ ] 确认新页面文案、真实产品规格、商家联系方式后再发布；记下可回滚的旧 deploy。
