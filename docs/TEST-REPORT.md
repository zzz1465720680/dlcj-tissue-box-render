## 方法与限制

测试环境为 Linux、Node.js 22.16.0、全局 TypeScript 5.8.3、Python Playwright 和系统 Chromium。项目锁定的 TypeScript 是 5.9.3；本次未下载该锁定依赖集。

运行环境不能下载 npm 依赖；因此没有完成 `npm ci`、完整 `tsc --noEmit` 或正常 Vite 构建。离线编译仅做转译及语法诊断；不能把它当成类型检查成功。

系统 Chromium 的主页面导航被环境策略阻止，测试没有修改系统策略。测试通过 `page.set_content` 嵌入真实应用，路由真实本地 JS、CSS、图片资源；仅在测试层替换 URL/History、localStorage 和 IndexedDB 后端。原 UI、React、事件处理、保存/读取调用、Schema 及 JSON 内容生成照常执行。

因此，浏览器检查证明的是：在这个明确的边界模拟环境中，渲染和业务行为符合检查条件。它不证明真实地址栏跳转、原生数据库持久性、跨页面恢复、Safari 隐私限制或生产网络正常。

环境不能建立 WebGL 上下文。已检查原模型不可用时的提示、禁用相机与 PNG，以及可用的 JSON 备份。没有生成任何冒充 3D 实测的截图。
